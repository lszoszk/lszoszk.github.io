🎬 <a href="https://lszoszk.github.io/ECHR-Dashboard/"><strong>HUDOC Researcher</strong></a>, an independent toolkit built on HUDOC data for working with the case law of the European Court of Human Rights, is now available in beta (<a href="https://lszoszk.github.io/tools/hudoc-researcher/#film">a 100-second film</a> shows how it works). Every judgment is split into the Court's own paragraphs, which can be searched with keywords and Boolean operators or, when only the facts are known, by describing the case in plain words (Semantic Search); the beta holds all judgments in English (over 20,000) as well as the judgments HUDOC publishes only in French (over 9,000). A Check tool compares every citation and quotation in a draft with the text of the judgment, and through the MCP server and the Claude skill an AI assistant can quote the Court verbatim, with the case, application number and paragraph. Every paragraph links to the same paragraph in HUDOC, which remains the authoritative source.
